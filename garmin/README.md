# PULZ Garmin

This folder contains a Garmin Connect IQ starter app for the PULZ watch experience.

## What it does today

- Shows a simple PULZ watch screen.
- Lets the user mark `Calm`, `Urge`, or `Pause`.
- Displays a short breathing prompt when pause is triggered.

## Open it

1. Install the Garmin Connect IQ SDK.
2. Open this folder as a Connect IQ project.
3. Run it in the simulator for a supported watch.
